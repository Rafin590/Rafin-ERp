ওয়েবসাইট API কানেক্ট ও অটোমেটিক অর্ডার রিসিভার

আপনার WordPress, WooCommerce, Custom Landing Page বা React/Next.js সাইটের সাথে ১-ক্লিকে ERP যুক্ত করুন।

ইনকামিং অর্ডার রিসিভার Webhook URL POST Active

এই URL টি আপনার WooCommerce Webhook অথবা Custom Landing Page ফর্মে পেস্ট করুন।

সিকিউরিটি Webhook Secret Token Header: X-Omni-Signature

অথোরাইজেশন ভেরিফিকেশনের জন্য এই সিক্রেট টোকেন ব্যবহার করুন।

পদ্ধতি ১: WooCommerce Webhook Settings (কোনো কোড ছাড়া)

  1. WordPress Dashboard > WooCommerce > Settings > Advanced > Webhooks এ যান।
  2. Add Webhook এ ক্লিক করে Status দিন Active, Topic দিন Order created।
  3. Delivery URL এ উপরের Webhook URL এবং Secret এ Secret Key পেস্ট করুন।
পদ্ধতি ২: functions.php Snippet (অটোমেটিক Instant Push) 
// WooCommerce functions.php এ পেস্ট করুন
add_action('woocommerce_thankyou', 'omnistore_push_order_webhook', 10, 1);
function omnistore_push_order_webhook($order_id) {
    if (!$order_id) return;
    $order = wc_get_order($order_id);
    
    $payload = array(
        'order_id' => $order_id,
        'customer_name' => $order->get_billing_first_name() . ' ' . $order->get_billing_last_name(),
        'phone' => $order->get_billing_phone(),
        'address' => $order->get_billing_address_1() . ', ' . $order->get_billing_city(),
        'total_amount' => $order->get_total(),
        'courier' => 'Steadfast',
        'items' => array()
    );
    foreach ($order->get_items() as $item) {
        $payload['items'][] = array('name' => $item->get_name(), 'qty' => $item->get_quantity(), 'price' => $item->get_total());
    }

    wp_remote_post('https://api.omnistore-erp.com/v1/webhook/orders/receive', array(
        'method' => 'POST',
        'headers' => array('Content-Type' => 'application/json', 'X-Omni-Secret' => 'omni_whsec_9847291847289'),
        'body' => json_encode($payload)
    ));
}
